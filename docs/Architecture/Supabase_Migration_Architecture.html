3
Supabase creates user

Session returned

5
Tokens auto-managed
Supabase client handles storage and refresh automatically

Code Comparison

Before (Custom)
// Frontend calls YOUR backend const response = await fetch( 'http://localhost:8000/api/auth/signup', { method: 'POST', body: JSON.stringify({ email, password, role }) } ); // Your Python code handles JWT
After (Supabase)
// Frontend calls Supabase directly const { data, error } = await supabase .auth .signUp({ email: 'user@example.com', password: 'password123', options: { data: { name, role } } }); // Supabase handles EVERYTHING

⚡ Real-Time Sync

When teacher publishes a class, student's app updates instantly via WebSocket:

1
Teacher clicks "Publish"
Updates class in Supabase: is_published = true
2
Supabase Realtime detects change
Database trigger fires on UPDATE
3
Find all subscribers
Student's app is subscribed to classes table
4
Push via WebSocket
Student's app receives the change immediately
5
UI updates instantly!
"New class available!" - no refresh needed

Subscription Code

Desktop (React/TypeScript)
const channel = supabase .channel('my-classes') .on( 'postgres_changes', { event: '*', schema: 'public', table: 'classes' }, (payload) => { console.log('Update!', payload); fetchClasses(); } ) .subscribe();
Mobile (Flutter/Dart)
final channel = supabase .channel('my-classes'); channel .onPostgresChanges( event: PostgresChangeEvent.all, schema: 'public', table: 'classes', callback: (payload) { print('Update!'); ref.invalidate(classesProvider); }, ) .subscribe();

🛡️ Security: Row Level Security

Row Level Security (RLS) means security is enforced at the database level, not the app level:

Without RLS

App code checks permissions:

if (user.id === mistake.student_id) { // Allow access } // But what if someone bypasses // the app and calls API directly? // DATA LEAKS! 😱
With RLS

Database enforces permissions:

CREATE POLICY "Students see own" ON mistakes FOR SELECT USING (auth.uid() = student_id); -- Even direct API calls are blocked! -- Database returns: [] ✅

Key RLS Policies

Table Policy
classes Teachers see own classes; Students see published classes they're in
mistakes Students see own mistakes; Teachers see their students' mistakes
teacher_students Teachers can manage their own relationships
