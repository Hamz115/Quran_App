# QuranTrack Final v2.0.0 GitHub Release Build

**Date:** 2026-07-26
**Release:** v2.0.0
**Status:** Published successfully through GitHub Actions

## Decision

Hamza confirmed that QuranTrack should continue using the established GitHub Actions release process, that all current Android and Windows artifacts should use version `2.0.0`, and that a paid Windows Authenticode certificate is not required for this release. SmartScreen may therefore show the documented first-install warning.

The repository already had a Tauri updater signing key pair configured correctly: the updater public key is in `quran_frontend/src-tauri/tauri.conf.json`, while `TAURI_SIGNING_PRIVATE_KEY` and its password were already stored as protected GitHub Actions secrets. No key generation or rotation was required, and no private key was exposed.
