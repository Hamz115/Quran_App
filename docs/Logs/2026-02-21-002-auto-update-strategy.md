## Objective

## Summary

Discussed auto-update strategy for the Tauri desktop app. The recommended approach is Tauri's built-in updater plugin (`@tauri-apps/plugin-updater`) with GitHub Releases as the hosting backend. This gives a zero-cost, secure, one-click update experience for non-technical users.

## Context

- App will be distributed to siblings/family who are Quran teachers for real-world testing
- Users are non-technical — updates must be seamless (click a button or automatic)
- Developer (Hamza) will be actively fixing bugs and adding features during this testing phase
- Need a reliable, low-friction pipeline: code change → build → ship → users get it

## Strategy: Tauri Auto-Updater + GitHub Releases

### Developer Workflow
1. Fix bug or add feature, commit to main
2. Bump version in `src-tauri/tauri.conf.json` (e.g. `1.0.0` → `1.0.1`)
3. Run `tauri build` — produces installer (.msi/.exe) + update signature file
4. Create a GitHub Release (tag: `v1.0.1`), upload the build artifacts
5. Done — users get notified on next app launch

### User Experience
- App launches → checks GitHub for latest version (via `latest.json` endpoint)
- If newer version exists → toast/dialog: "Update available! (v1.0.1)"
- User clicks "Update" → downloads in background → installs → restarts
- Alternative: fully silent auto-update on launch (no user action needed)

### Technical Details

**Plugin:** `@tauri-apps/plugin-updater` (Tauri v2 built-in)

**Update endpoint:** `https://github.com/Hamz115/Quran_App/releases/latest/download/latest.json`

**How it works:**
- `latest.json` is auto-generated by Tauri's build process
- Contains download URLs + cryptographic signatures for each platform
- Updater compares remote version vs installed version
- Downloads are signature-verified (no tampered builds can be installed)

**Signing:** One-time setup — generate a key pair, public key goes in `tauri.conf.json`, private key used during build to sign the update bundles

### Why GitHub Releases
- Free (no server costs, no hosting fees)
- Reliable (GitHub CDN)
- Tauri updater has native GitHub Releases support
- Version history visible at `/releases` page
- Can attach release notes (changelogs) to each version

## Flutter Mobile Strategy

For the APK (Android):
